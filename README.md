# BookMedik API

API REST desarrollada con Django REST Framework.

## Tecnologías

- Python
- Django
- Django REST Framework
- JWT
- MySQL

## Instalación

1. Clonar repositorio
2. Crear entorno virtual
3. Instalar requirements.txt
6. Ejecutar migraciones
7. Crear superusuario
8. Ejecutar servidor
